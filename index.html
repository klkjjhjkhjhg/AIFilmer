🧱 技术栈

端云三层分层 + 关键组件，可在下方切换查看

端 侧

移动端

采集摄像头与传感器数据，由端侧 NPU 完成第一轮推理。

📷 AVFoundation🧩 Core ML⚙️ Metal
桥 接

Shot Protocol（镜头指令协议）

将 LLM 输出的 JSON 指令转译为端侧可执行的相机动作，是端云两侧共同遵循的协议层。

📐 JSON Schema🔁 双循环
云 端

云端服务

承担 1~3 秒级的创意决策：镜头拆解、节奏编排与分镜脚本生成。

☁️ FastAPI🤖 LLM 适配🎬 多镜头脚本

👁 实时场景理解

摄像头持续采集，由端侧模型在毫秒级内完成画面内容理解，数据不离开本机。

场景分类 · 室内 / 逆光 / 夕阳 / 夜景等场景的自动判定
人脸与人体检测 · 锁定主体坐标，支持稳定跟拍
主体跟踪 · 在主体位移时持续保持锁定
光照估计 · 判断当前曝光是否过曝或欠曝

🧠 镜头脚本规划

接收用户主题后，由云端 LLM 拆解为 3~5 个有节奏的镜头并生成 ShotSpec。

主题拆解 · 由自然语言主题生成结构化镜头清单
节奏编排 · 按远景—近景—特写等构图递进排布
方向提示 · 为下一镜头计算三维方向与构图引导
脚本可编辑 · 支持用户在拍摄前手动调整并重新生成

📷 相机控制

由 Capability Layer 在端侧实时执行对焦、调参与录制指令。

对焦与曝光 · 毫秒级响应镜头策略变化
云台与防抖 · 配合手机 OIS + EIS 系统级能力
多镜头录制 · 支持自动续录与跨镜头拼接
构图引导 · 在屏幕上叠加取景框与位置提示

🎨 调色调光

依据场景识别与脚本意图，主动决策曝光、白平衡与色彩风格，而非简单套用滤镜。

曝光与白平衡 · 实时跟随场景动态调整
肤色保护 · 人物特写场景下保持肤色自然准确
风格预设 · 暖色 / 冷色 / 胶片等 LUT 基线
跨镜头一致性 · 多镜头间保持统一调性

☁️ 云端服务

1~3 秒级的创意决策由云端 LLM 承担，端侧能完成的推理不进入云端。

多模型适配 · OpenAI / Anthropic / Qwen 等可热切换
脚本缓存 · 同一主题的拆镜结果可复用
隐私边界 · 用户视频仅本机存储，API Key 仅存于云端
离线降级 · 无网络时由端侧模型接管基础能力

📝 使用流程

三步完成一次拍摄

1
✍️

输入主题

2
🤖

脚本拆解与确认

3
📱
