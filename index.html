AIFilmer

你的 AI 摄影师。
你说一句想拍什么，AI 帮你拆好镜头、自己拍、自己调色——你只管对准。

📱 iPhone App 🤖 AI 自主拍摄 🎬 多镜头连续创作

✅ 能不能做？

用的都是成熟技术，不是科幻

👤

人物特写

AI 自动识别人脸、对焦肤色、给画面加上温暖色调。

🌅

风景静物

AI 识别夕阳/逆光/夜景，自动调整曝光与冷暖色调。

☕

日常 Vlog

AI 跟踪主体、保持中景构图，自动串起一段段镜头。

当前限制：iPhone 14 及以上；单一主体 / 一般光照最佳；多人、急别运动、极弱光场景会降级。

🛠️ 怎么做的？

感知 → 决策 → 拍摄，三步搞定

👁

感知

手机摄像头看到画面，本地 AI 识别场景、人脸、主体位置。

→
🧠

决策

本地 + 云端协作，决定曝光、调色、构图、下一镜头。

→
🎬

拍摄

自动调焦、调参、调色，连续录制成片。

🧱 用什么搭起来的？

三层结构 + 几个关键技术，点开看看各能做什么

端 侧

手机本地

摄像头、传感器、芯片上的小模型。你看到的画面都在这一层先过一遍。

📷 AVFoundation🧩 Core ML⚙️ Metal
桥 接

Shot Protocol（镜头指令协议）

AI 输出 JSON → 端侧执行器翻译成具体动作。一套"AI 和相机都能听懂的语言"。

📐 JSON Schema🔁 双循环
云 端

云端大脑

负责慢思考：拆镜头、规划节奏、写分镜脚本。

☁️ FastAPI🤖 LLM 适配🎬 多镜头脚本

👁 实时看懂画面

手机摄像头一直开着，本地小模型在毫秒级告诉你"现在画面里有什么"——不需要传回云端。

场景分类 · 室内 / 夕阳 / 逆光 / 夜景，自动判断
人脸 / 人体检测 · 锁定主体位置，跟拍不丢
主体跟踪 · 人物走动也能牢牢锁住
光照估计 · 知道当前是过曝还是太暗

🧠 规划镜头

你说一句"夕阳下的咖啡店"，云端 LLM 帮你拆出 3~5 个有节奏的镜头，写好脚本。

主题拆解 · 一句话 → 镜头清单
节奏编排 · 远→近→特写，避免平铺直叙
方向提示 · 给用户提示"下一步对准哪里"
脚本可改 · 用户看完可手动调整再开始拍

📷 控制相机

AI 决定完之后，端侧实时执行：调焦、调参、开始录。

对焦 / 曝光 · 毫秒级响应
云台 / 防抖 · 配合手机 OIS + EIS
录制 / 续录 · 多镜头自动拼接
构图引导 · 屏幕上画框提示位置

🎨 调色调光

AI 不只是"调滤镜"——它会根据场景和脚本意图，主动决定曝光、白平衡、风格。

曝光 / 白平衡 · 实时跟场景走
肤色保护 · 人物特写时保证肤色自然
风格预设 · 温暖 / 清冷 / 胶片感
镜头间一致 · 多镜头拼接不掉风格

☁️ 云端大脑

1~3 秒的"慢思考"由云端 LLM 承担：拆镜、写脚本、规划节奏。本地能干的绝不上云。

多模型适配 · OpenAI / Anthropic / 通义千问 可切换
脚本缓存 · 同一主题不重复算
隐私优先 · 用户视频只存本机，API Key 只在云端
降级方案 · 无网时本地模型接管

📝 怎么用？

3 步开心用

1
✍️

2
🤖

3
