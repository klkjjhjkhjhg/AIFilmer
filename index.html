✨ MVP 能力亮点

三大演示场景 · 端侧为主 · 云侧为备

⚡

Fast Loop · 实时闭环

端侧 NPU 推理（场景识别 / 主体检测 / 跟踪）+ 系统级相机 API（AVFoundation），≤ 500ms 端到端。

🎨

主动调色 · 不止建议

Metal Shader 实时 LUT，根据脚本意图主动调整色温 / 对比度 / 饱和度，含肤色保护。

🧠

Creative Loop · 云端大脑

LLM 拆镜本 + MLLM 主体匹配 + 三维方向提示，1~3s 决策周期，断网可用预制脚本。

📐

Shot Protocol · 镜头语言协议

MCP-like 协议层把 LLM 输出转换成可执行的相机动作序列，schema 冻结、可扩展。

🎯

三维方向提示

下一镜头的拍摄主体在空间哪里？算法给出"向左 / 向右 / 请旋转手机寻找"提示并自动收敛。

🔒

隐私优先

用户视频与脚本完全本地存储；上传云侧的只有主题文本与裁剪后的主体小图（< 50KB）。
