🎯
YOLOv8-Nano
Ultralytics · 主体检测（80 类 COCO）
端侧 详情 ▾

AIFilmer Fast Loop 的"眼睛"。每帧定位画面中的主体（招牌、咖啡杯、街景元素），输出 192×192 检测结果。注意：YOLO 是闭集检测器，只能识别训练过的类别，所以这里用它做"通用主体存在性"检测，开放词汇描述交给云端 Grounding DINO。

输入1080p frame → 192×192 归一化张量
输出[class, bbox(x,y,w,h), score]
示意 · 参考 Ultralytics 官方 yolov8.yaml
官方文档 → GitHub →
🔗
ByteTrack
ECCV 2022 · 多目标跟踪（数据关联）
端侧 详情 ▾

接收 YOLOv8n 每帧的检测框，做两阶段关联（高置信 + 低置信），避免遮挡时丢目标。配合 Kalman 做轨迹平滑。它不做"按描述找物体"——只负责把检测到的目标连成时间线。

输入每帧 N 个 bbox + score
输出每个 tracklet 的稳定 ID + 平滑 bbox
示意 · 关联几乎每个检测框（含低置信）
GitHub → 论文 →
📈
Kalman Filter (2D)
经典算法 · 轨迹平滑
端侧 详情 ▾

8 状态 [x, y, w, h, vx, vy, vw, vh] 常速度模型。在 ByteTrack 输出上加平滑，让跟踪不抖、不漂移。

输入当前帧 bbox（带噪声）
输出平滑后 bbox + 不确定椭圆
Predict 拓宽不确定椭圆 → Update 用测量收窄
经典教程 → Wikipedia →

LLM · GPT-4o / Claude / Qwen
文本任务 · 拆镜本（不需要看图）
云端 详情 ▾

接收主题文本，按 JSON Schema 输出 N 个镜头的 ScriptSpec（含 type、duration、color_intent、composition_hint 等）。纯文本任务，不需要视觉能力，JSON-mode 严格度 99.7%。

输入theme + shot_count + style_profile
输出ScriptSpec（4 个镜头，~1.5K tokens）
架构未公开，示意 Shot Protocol 流程

🔍
Grounding DINO 1.6 Pro
开放词汇检测 · "按描述找物体画框"
云端 详情 ▾

接收自然语言描述（如"咖啡店门口的猫"）+ 图像，返回 bbox。专门做定位，不生成废话描述。为什么不用 GPT-4o Vision：VLM 擅长"看图回答问题"，不是"按描述找物体"；Grounding DINO 是 2026 开放词汇检测精度天花板（LVIS zero-shot AP 51.1%，~300ms）。

输入"咖啡店门口的招牌" + frame (裁剪 < 50KB)
输出bbox_norm + score + matched_phrase
示意 · Swin+BERT 双编码 + Cross-Attention 融合 + DINO 解码
GitHub → 论文 → Grounded-SAM 2（视频跟踪）→
🎨
Metal Shader · 3D Color LUT
Apple · 端侧实时调色
端侧 详情 ▾

对每一帧应用 3D LUT：色温偏移、对比度、饱和度、肤色保护。色温 ±15% / 饱和度 0.8~1.2 / 对比度 0.9~1.1，整段共用 StyleProfile=warm_sunset。

输入CVPixelBuffer + StyleProfile 参数
输出调色后的 CVPixelBuffer（写到 AVAssetWriter）
