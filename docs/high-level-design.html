1. 一句话定位

AIFilmer MVP = 一款 iOS 旗舰 App，让 AI 接管"拍摄决策"，把 iPhone 变成自主摄影师。用户保留指向权（手持移动设备），AI 保留拍摄权（构图、调色、参数、下一分镜、镜头语言）。LLM 在云侧生成"镜头语言协议"（MCP-like 协议），端侧执行。

6. 关键架构决策

ADR-001 · 双环分层架构
决策 / 理由 / 影响
  • 决策：Fast Loop（≤ 500ms，端侧）与 Creative Loop（1~3s，云云协同）物理隔离，通过共享状态通信。
  • 理由：满足延迟预算；端云分层清晰；扩展性好。
  • 影响：Director 必须是无锁的纯消息路由；Capability Layer 接口要稳定。
ADR-002 · 端侧优先 + 云侧可选
决策 / 理由 / 影响
  • 决策：所有能力标记 Online-Required / Online-Optional / Offline-Only；MVP 不允许 Online-Required 阻塞主流程。
  • 理由：断网时核心拍摄能力必须可用。
  • 影响：脚本生成、主体匹配、方向提示在断网时降级（见 §7）。
ADR-003 · Shot Protocol 协议先行
决策 / 理由 / 影响
  • 决策：定义 MCP-like 协议，所有 LLM 输出必须遵守；协议 schema 冻结。
  • 理由：协议稳定后再扩展能力，避免每加一个能力重写 LLM 输出。
  • 影响：见 详细设计 §4。
ADR-004 · 设备白名单
决策 / 理由 / 影响
  • 决策：MVP 仅在 iPhone 14 及以上 iOS 17+ 设备上保证完整能力。
  • 理由：不同 iPhone 机型 AVFoundation 行为差异巨大；MVP 不为兼容性牺牲体验。
  • 影响：App 启动时检测设备能力，不达标给出明确提示。

7. 降级策略

7.1 网络降级

能力在线离线
LLM 拆镜本✅ 正常⚠️ 用预制模板（3 套）

10. 跨切关注点

10.1 可观测性

  • 客户端：本地日志 + 关键事件埋点（无埋点上报，保护隐私）
  • 服务端：调用日志、LLM token 消耗、错误率
  • 演示场景：三类场景各保留一组"黄金路径"录制视频，便于回归

10.2 安全与隐私

  • App 端视频全部本地存储
  • 上传云侧的只有：脚本生成请求（主题文本）+ 主体匹配请求（裁剪后的主体小图）
  • LLM API Key 仅在后端持有，不下发到客户端
  • iOS 端遵守 Apple 隐私政策

10.3 性能

  • Fast Loop 延迟预算：500ms（Camera capture 50ms + Inference 50ms + Driver 100ms + Buffer 300ms）
  • Creative Loop 决策周期：1~3s
  • 录制降级：1080p / 30fps（不抢 NPU）
