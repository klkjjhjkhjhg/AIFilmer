# AIFilmer MVP — 概要设计

> **文档版本**: v1.0  
> **结构**: C4 模型（System Context → Container → Component）  
> **配合阅读**: [需求分析](./requirements-analysis.md) · [详细设计](./detailed-design.md)  
> **目标读者**: 架构师 / Tech Lead / 后端负责人

---

## 0. 一句话定位

**AIFilmer MVP = 一款 iOS 旗舰 App，让 AI 接管"拍摄决策"，把 iPhone 变成自主摄影师。** 用户保留指向权（手持移动设备），AI 保留拍摄权（构图、调色、参数、下一分镜、镜头语言）。LLM 在云侧生成"镜头语言协议"（MCP-like 协议），端侧执行。

### 2.2 容器清单

| 容器 | 部署位置 | 职责 | 技术选型 |
|---|---|---|---|
| **iOS App** | 用户设备 | 全功能集成：UI / 双环 / 端侧推理 / 拍摄执行 | Swift 5.9+, SwiftUI, AVFoundation, Core ML, Metal |
| **Cloud Backend** | 云服务 | 脚本生成、主体匹配、方向提示 + 协议层 | Python + FastAPI（建议）/ Node.js |
| **LLM Service** | 第三方 | 提供底层大模型推理能力（GPT-4o / Claude / Qwen-VL） | 第三方 API |

> **注意**：MVP 不做"原生后端 + 第三方 LLM"的双层架构，**Cloud Backend 直接代理 LLM 调用**，避免 MVP 阶段过度分层。

### 2.3 容器间通信

| 通信路径 | 协议 | 频率 | 数据量 |
|---|---|---|---|
| iOS App ↔ Cloud Backend | HTTPS / REST | 1~3 次/拍摄 | 每次 < 50KB 请求 / < 10KB 响应 |
| iOS App ↔ LLM Service | 由 Backend 代理，App 不直连 | — | — |
| iOS App ↔ iOS 系统服务 | 原生 API | 实时 | 视频流 30 fps |

## 5. 关键架构决策（ADR 摘要）

> 完整 ADR 见 [detailed-design.md §11](./detailed-design.md)。

### ADR-001 采用"双环分层"架构
- **决策**：Fast Loop（≤ 500ms，端侧）与 Creative Loop（1~3s，云云协同）物理隔离，通过共享状态通信。
- **理由**：满足延迟预算；端云分层清晰；扩展性好。
- **影响**：Director 必须是无锁的纯消息路由；Capability Layer 接口要稳定。

### ADR-002 端侧优先 + 云侧可选
- **决策**：所有能力标记 *Online-Required / Online-Optional / Offline-Only*；MVP 不允许 *Online-Required* 阻塞主流程。
- **理由**：断网时核心拍摄能力必须可用。
- **影响**：脚本生成、主体匹配、方向提示在断网时降级（见 §6）。

### ADR-003 Shot Protocol 协议先行
- **决策**：定义 MCP-like 协议，所有 LLM 输出必须遵守；协议 schema 冻结。
- **理由**：协议稳定后再扩展能力，避免每加一个能力重写 LLM 输出。
- **影响**：见 [详细设计 §4](./detailed-design.md)。

### ADR-004 设备限定白名单
- **决策**：MVP 仅在 iPhone 14 及以上 iOS 17+ 设备上保证完整能力。
- **理由**：不同 iPhone 机型 AVFoundation 行为差异巨大；MVP 不为兼容性牺牲体验。
- **影响**：App 启动时检测设备能力，不达标给出明确提示并禁用相关功能。

## 6. 降级策略

### 6.1 网络降级

| 在线 | 离线 |
|---|---|
| ✅ LLM 拆镜本 | ❌ 用预制模板（3 套预制脚本） |
| ✅ MLLM 主体匹配 | ⚠️ 用端侧轻量匹配（精度低） |
| ✅ 云侧三维方向生成 | ⚠️ 仅"画面内相对位置"，不生成新方向 |
| ✅ LLM 镜头修改 | ❌ 不支持修改，需手动重录 |

### 6.2 设备能力降级

| 设备不达标 | 表现 |
|---|---|
| NPU 不可用 | 端侧推理降级为 CPU 模式（延迟升高） |
| 不支持 `videoZoomFactor` | 禁用数字变焦提示 |
| 不支持 `AE/AV` 自定义 | 提示用户开启"手动接管"（MVP 不支持） |

## 7. 数据流（核心场景）

### 7.1 场景 A：用户输入主题 → 生成镜本

```
[Presentation] --input-->[Director] --generate_script--> [Shot Protocol Client]
                                                              │
                                                              │ HTTPS POST
                                                              ▼
                                                       [Cloud Backend]
                                                              │
                                                       [LLM Provider]
                                                              │
                                                       ◄──── ShotSpec JSON
                                                              │
                                                       [Shot Protocol Registry]
                                                       · 校验 schema
                                                       · retry if invalid
                                                              │
                                                              ▼
[Director] <--ShotSpec--[Presentation] --render cards-->
```

### 7.2 场景 B：单镜头拍摄

```
[Camera (AVFoundation)] --frame (30fps)--> [Vision Pipeline]
                                              │
                                              │ scene / subject / track
                                              ▼
                                          [Fast Loop]
                                              │
                                              │ camera_action + subject_state
                                              ▼
                                          [Director SharedState]
                                              │
                  ┌───────────────────────────┼───────────────────────────┐
                  ▼                           ▼                           ▼
           [Camera Driver]            [Color Engine]            [Presentation HUD]
           · setExposureOffset         · 更新 LUT 参数        · 渲染决策文本
           · setFocusPoint             · Metal shader 编译
           · setWhiteBalanceMode
```

### 7.3 场景 C：推荐下一镜头

```
[Director] --shot_duration_reached--> [Creative Loop]
                                              │
                                              │ next_shot_spec + current_frame
                                              ▼
                                  [Shot Protocol Client]
                                              │ HTTPS
                                              ▼
                                   [SubjectMatch Service]
                                              │
                                              │ matched_subject_id (or null)
                                              ▼
                                  [Director]
                                              │
                                              │ compute_direction
                                              ▼
                          [Presentation] --render next_shot_card-->
```

## 9. 跨切关注点

### 9.1 可观测性

- **客户端**：本地日志 + 关键事件埋点（无埋点上报，保护隐私）
- **服务端**：调用日志、LLM token 消耗、错误率
- **演示场景**：三类场景各保留一组"黄金路径"录制视频，便于回归

### 9.2 安全与隐私

- App 端视频**全部本地存储**
- 上传云侧的只有：脚本生成请求（主题文本）+ 主体匹配请求（裁剪后的主体小图）
- LLM API Key 仅在后端持有，不下发到客户端
- iOS 端遵守 Apple 隐私政策

### 9.3 性能

- Fast Loop 延迟预算：500ms（Camera capture 50ms + Inference 50ms + Driver 100ms + Buffer 300ms）
- Creative Loop 决策周期：1~3s
- 录制降级：1080p / 30fps（不抢 NPU）

## 10. 总结

| 维度 | 决策 |
|---|---|
| 架构形态 | C4 Level 2：iOS App + Cloud Backend + LLM Provider |
| 核心模式 | 双环分层（Fast Loop + Creative Loop） |
| 通信协议 | HTTPS REST + Shot Protocol（应用层） |
| 关键技术选型 | Swift / SwiftUI / AVFoundation / Core ML / Metal / FastAPI |
| MVP 边界 | iOS 17+，iPhone 14+，单设备，三类演示场景 |
